# モバイル動作確認チェックリスト (M10)

要件定義 1.4 / 9 章 / 実装計画 M10 に基づく、MVP 段階の動作確認項目。

対象ブラウザ:

- iOS Safari (iPhone SE / iPhone 14 Pro / iPad)
- Android Chrome
- 念のため Chrome / Safari / Firefox の最新デスクトップ版

## 表示・レイアウト

- [ ] 縦持ちで HUD / Canvas / メニューが上から順に並び、画面外には出ない
- [ ] ノッチ / ホームバー領域 (`env(safe-area-inset-*)`) と被らない
- [ ] HUD が右端で切れずに「所持金 / 日付 / Lv + EXP バー」が読める
- [ ] PixiJS Canvas が画面いっぱいに拡縮されつつピクセルがぼやけない
  (image-rendering: pixelated)
- [ ] 横向きにしても破綻しない (理想的には縦持ちプレイ前提)

## タップ操作

- [ ] 下部メニュー (建てる / 育てる / 出荷 / ステータス / ≡) が全部押せて、
      タップ後すぐに反応する (300ms 遅延がない)
- [ ] 速度切替バーが押せ、選択中の倍率がハイライトされる
- [ ] 通知ベル (!) が押せ、ドロップダウンが画面内に収まる
- [ ] モーダルの × ボタンが押しやすい (44×44 以上)
- [ ] スキルポイントの + ボタンが押しやすい
- [ ] 「建てる」モード中、空きマスをタップすると配置でき、不可マスでは
      赤いトーストが出る

## ゲームプレイ

- [ ] 新規開始から `建てる → 種まき → 水やり → 高速進行 → 収穫 → 出荷` の
      一連の流れが完走できる
- [ ] 速度 8× で時間進行が体感できる
- [ ] 収穫期到達でベルバッジが赤く点灯し、ハウス右上にも緑ドットが出る
- [ ] 水切れの黄ドットが出る
- [ ] レベルアップでトースト + ステータスでSPを振れる

## 永続化

- [ ] リロード後にレベル / 所持金 / ハウス / 在庫 / プロット状態が
      復元される
- [ ] 設定モーダルで「エクスポート」したコードを別ブラウザの「インポート」に
      貼り付け、ほぼ同じ状態になる
- [ ] 「最初からやり直す」で localStorage がクリアされる

## ジェスチャ抑止

- [ ] ダブルタップで画面が拡大しない (touch-action: manipulation)
- [ ] ピンチで画面が拡大しない (viewport maximum-scale=1.0)
- [ ] 下にスワイプしてもページ自体は動かない (overscroll-behavior: none)
- [ ] Canvas 上のスワイプでスクロールが発生しない (touch-action: none)

## パフォーマンス

- [ ] iPhone SE クラスでも 60fps を概ね維持する
- [ ] ハウス 5 棟まで配置しても明らかな fps 低下がない
- [ ] バックグラウンドにすると tick が止まる (CPU を食わない)
- [ ] アプリに戻ったとき lastTickAt が補正され時刻が暴走しない

## 既知の非対応事項 (MVP 範囲外)

- バックグラウンド OS 通知 (iOS アプリ化のタイミングで追加)
- オフライン進行 (帰ってきたら 1 週間分が走るような挙動は無し)
- 長時間プレイ時の WebGL ロスト復帰
