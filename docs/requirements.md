# 大玉トマト農園シミュレーションRPG 要件定義書

> 本書は、カイロソフト「大空ヘクタール農園」風の経営シミュレーションRPGを、**大玉トマト × ビニールハウス特化**というテーマで Web ブラウザ向けに開発するための要件定義書である。
>
> - 対象読者: 企画・開発・デザイン・将来の協力者
> - 状態: ドラフト（フェーズ1=MVP の範囲は確定、フェーズ2=拡張は方向性レベル）
> - 言語: 日本語 / Markdown

---

## 1. ゲーム概要

### 1.1 一言コンセプト
**「大玉トマトだけを極める、ビニールハウス農園経営シミュレーションRPG」**

### 1.2 ジャンル
シミュレーション + 経営 + 軽量RPG（農園主と従業員の育成要素）。

### 1.3 ターゲットプレイヤー
- カイロソフト作品（大空ヘクタール農園、開発物語、ゲーム発展国++ など）が好きな層
- ブラウザで隙間時間に遊べる経営シムを探している層
- 1作物に絞り込んだ「やり込み特化」を楽しめる層

### 1.4 想定プレイ環境
- PC / スマホのモダンブラウザ（Chrome / Safari / Edge / Firefox 最新版）
- 1セッション 5〜15 分、長期プレイで 10 時間以上

### 1.5 カイロ作品との関係と差別化
- **類似点**: グリッド配置、施設拡張、雇用、研究、評価、年単位の進行、ドット絵の世界観
- **差別化**: 作物を**大玉トマトのみ**に絞ることで、品質グレード・品種改良・栽培技術・市場戦略に深く踏み込む。「広く浅く」ではなく「狭く深く」のカイロ風。

## 2. ゲームのコアループ

```
[1] ハウスを建てる
        ↓
[2] 大玉トマトの苗を植える
        ↓
[3] 毎日の管理（水やり・追肥・温度調整・摘芯）
        ↓
[4] 収穫（量と品質グレードが決まる）
        ↓
[5] 出荷・販売（市場価格 × グレード × 量）
        ↓
[6] 収益で拡張・研究・雇用 ──→ [1] へ戻る
```

このループを**1日〜1週間で1周**まわせることを目標にする。

---

## 3. 時間とターン制

- 1ゲーム日 = **朝 / 昼 / 夕 の3フェーズ**で構成。各フェーズで作業アクションを1〜数回行う。
- 1ゲーム年 = **春 / 夏 / 秋 / 冬 の4季節**、各季節 30 日程度（合計 120 日 / 年）。
- 季節ごとに気温・日照条件が変化し、ハウス内環境への影響度が変わる（夏は高温障害、冬は加温コスト）。
- **オート進行**: 「次のフェーズへ」「次の日へ」ボタンで時間を進める。完全自動進行はフェーズ2で検討。
- 一時停止は常時可能。リアルタイム要素は持たない（タイクーン系のターン進行）。

## 4. ゲームシステム — フェーズ1（MVP）

> MVP の到達目標: **「ハウスを建てる → 大玉トマトを育てる → 売る → 拡張する」が一通り成立し、農園主のレベルアップが体感できる**こと。

### 4.1 ビニールハウスシステム
- 農園は**グリッドマップ**（例: 16×12 マス）として表現。
- プレイヤーは空きマスに**ビニールハウス**（1棟=2×3マス想定）を建設。
- ハウスには**栽培区画（Plot）が複数**含まれる（例: 1棟 = 6 区画）。
- 初期コスト、維持費（光熱・資材）を持つ。
- MVP ではハウスは1種類のみ。

### 4.2 大玉トマト栽培システム
- 1区画に 1株（または 1ロット）の大玉トマトを植える。
- **生育ステージ**: `播種 → 発芽 → 育苗 → 定植 → 開花 → 着果 → 肥大 → 収穫期`
- 各ステージは所定日数で進行し、適切なアクションを取らないと品質・収量が下がる。
- 必須アクション（MVP）:
  - **水やり**: 不足で枯死/品質低下、過剰で根腐れ
  - **追肥**: 着果〜肥大期にかけて品質を底上げ
- 任意アクション（拡張余地として後述）: 摘芯、誘引、温度調整など

### 4.3 収穫と品質
- 収穫量（kg）と品質グレード（**S / A / B / C**）が決まる。
- グレードを決めるパラメータ（MVPでは下記のみ）:
  - 管理スコア（水やり/追肥の的確さ）
  - ハウス性能（MVPでは固定）
  - 農園主の栽培スキル補正
- 各グレードに**期待単価**を設定し、単価差を体感できるバランスにする。

### 4.4 出荷・販売
- 収穫物は**在庫**に入る。
- 出荷画面で**ロット単位で出荷**し、即時換金。
- 市場価格は MVP では固定（フェーズ2で変動制）。

### 4.5 経済システム
- 通貨は1種類（円）。
- **支出**: 種苗、肥料、ハウス建設、修繕、（将来）給与・電気代
- **収入**: トマト出荷
- 残高がマイナスになる演出（借入 / ゲームオーバー）は MVP では持たず、**0円で停止**する穏やかな失敗にとどめる。

### 4.6 プレイヤー（農園主）の成長 — RPG要素
- 農園主は **レベル / 経験値 / スキル** を持つ。
- **経験値の獲得源**: 出荷、収穫、研究（将来）、イベント達成
- **基本スキル（MVP）**:
  - **栽培スキル**: 品質グレード補正 + ステージ進行誤差吸収
  - **経営スキル**: 出荷単価ボーナス、建設コスト割引
  - **目利きスキル**: 種苗の優良ロット取得確率
- レベルアップ時に**スキルポイント**を獲得し、任意のスキルに振る。
- レベルに応じて建設可能なハウス数の上限・解放要素を制御。

## 5. ゲームシステム — フェーズ2（カイロ風フルセット拡張）

> MVP の手応えがあれば順次追加。**優先順位は 10章のロードマップ**で管理する。

### 5.1 従業員システム（RPGパーティ風）
- ハローワーク的画面で**従業員を雇用**。
- 各従業員は固有の **職業 / レベル / スキル / 特性 / 給与** を持つ。
- 職業例: **栽培士・技術者・営業・研究員・運送員・アルバイト**
- ハウスや出荷場に**配置**することで効果を発揮（自動化、品質補正、研究促進等）。
- 経験値で**レベルアップ**し、ステータスが伸びる（パーティ育成感）。

### 5.2 研究開発
- 研究員配置とポイント蓄積で**技術ツリー**を解放。
- 技術例:
  - **潅水自動化**（水やり作業を不要化）
  - **養液栽培**（収量↑）
  - **補光 LED**（冬季の生育↑）
  - **CO2 施用**（糖度↑）
  - **総合環境制御**（複合効果）

### 5.3 品種改良
- 大玉トマトには**系統**がある（仮称: 桃太郎系、麗夏系、フルーツ系、地方在来系…）。
- 系統ごとに固有パラメータ（**糖度・玉伸び・耐病性・収量**）。
- 2系統を**交配**して新系統を作る。固定化までに数世代必要。
- 命名・登録によって市場プレミア（特産品扱い）を獲得。

### 5.4 施設拡張
- **高級ハウス**: ガラス温室、高軒高ハウス（性能↑、コスト↑）
- **設備**: 自動潅水、ヒートポンプ、選果機、出荷場、研究棟、休憩室
- 設備によって従業員の効率や品質グレード分布が変わる。

### 5.5 環境・リスク
- **気象**: 季節 × 天気（晴/曇/雨/雪/台風/寒波/猛暑）
- **病害虫**: うどんこ病、灰色かび病、コナジラミ、トマトキバガ等
- 対策（防除、品種選定、設備強化）と被害（収量↓・品質↓）でゲームに揺らぎを生む

### 5.6 イベント・評価
- **市場相場の変動**（季節要因 + ランダム）
- **品評会・コンテスト**（特定グレードを揃えて出品 → 賞金 + 評判）
- **メディア取材・地元祭り**
- **農園評価値 / ファン数**: 出荷量・品質・受賞で増加し、来客や価格にボーナス

### 5.7 ストーリー / 目的モード
- 年次目標（例: 3年目までに ○○ 万円達成、5年目に農林大臣賞）
- エンディング条件と「2周目以降の引き継ぎ」
- 自由モード（無期限プレイ）と挑戦モード（年数制限）

## 6. UI / 画面構成

すべての画面はピクセル基調で、上部に**ステータスバー**（所持金 / 日付 / 季節 / 農園主Lv）、下部に**操作メニュー**を固定。

### 6.1 タイトル画面
- 新規開始 / つづきから / 設定 / クレジット

### 6.2 農園トップビュー（メイン）
- グリッドマップにハウス・道・装飾物を俯瞰表示
- 「建てる」「育てる」「出荷」「研究」「人事」「ステータス」「次へ」ボタン

### 6.3 ハウス内画面
- ハウス内の栽培区画一覧
- 各区画の生育ステージ、必要アクションを表示
- 一括操作（全区画水やり等）と個別操作の両方を用意

### 6.4 出荷 / 市場画面
- 在庫一覧（グレード別 kg）
- 出荷ロットを組んで送信、収益を表示
- フェーズ2: 相場グラフ、出荷契約

### 6.5 ステータス画面
- 農園主のレベル / 経験値 / スキル振り
- フェーズ2: 従業員一覧、研究ツリー、品種カタログ、実績

### 6.6 メニュー / 設定 / セーブ
- セーブ / ロード（localStorage 3 スロット）
- BGM / SE 音量
- 言語（MVP は日本語のみ）

## 7. データモデル（概念設計）

> TypeScript 風の擬似コードで主要エンティティを示す。最終的なフィールドは実装時に確定。

```ts
// ゲーム全体の状態（セーブ単位）
type GameState = {
  version: string;
  player: Player;
  farm: Farm;
  market: MarketState;
  weather: WeatherState;
  research: ResearchState;     // フェーズ2
  employees: Employee[];        // フェーズ2
  calendar: { year: number; season: Season; day: number; phase: DayPhase };
  events: EventLog[];
};

type Player = {
  name: string;
  level: number;
  exp: number;
  skillPoints: number;
  skills: { cultivate: number; business: number; appraisal: number };
};

type Farm = {
  width: number;
  height: number;
  cash: number;
  greenhouses: Greenhouse[];
  inventory: HarvestStock[];   // グレード別在庫
};

type Greenhouse = {
  id: string;
  position: { x: number; y: number };
  size: { w: number; h: number };
  tier: number;                // フェーズ2で性能差
  plots: Plot[];
};

type Plot = {
  id: string;
  plant?: TomatoPlant;
  waterLevel: number;          // 0-100
  fertilizerLevel: number;     // 0-100
};

type TomatoPlant = {
  varietyId: string;
  stage: GrowthStage;          // 'seed' | 'sprout' | ... | 'harvest'
  daysInStage: number;
  careScore: number;           // 管理の累積評価
};

type TomatoVariety = {
  id: string;
  name: string;
  sweetness: number;
  size: number;
  disease: number;
  yield: number;
};

// フェーズ2
type Employee = {
  id: string;
  name: string;
  job: 'cultivator' | 'engineer' | 'sales' | 'researcher' | 'driver' | 'parttime';
  level: number;
  exp: number;
  skills: Record<string, number>;
  assignedTo?: string;          // greenhouse id 等
  salary: number;
};

type MarketState = { basePrice: Record<Grade, number>; trend: number };
type WeatherState = { today: WeatherKind; forecast: WeatherKind[] };
type Grade = 'S' | 'A' | 'B' | 'C';
type Season = 'spring' | 'summer' | 'autumn' | 'winter';
type DayPhase = 'morning' | 'noon' | 'evening';
type GrowthStage = 'seed' | 'sprout' | 'seedling' | 'planted' | 'flower' | 'fruit' | 'grow' | 'harvest';
type HarvestStock = { grade: Grade; kg: number };
type EventLog = { day: number; kind: string; message: string };

type ResearchState = { points: number; unlocked: string[]; current?: string };
```

## 8. 技術スタック・実装方針（推奨）

> 本章は **推奨構成** であり、実装計画フェーズで最終確定する。

| 項目 | 推奨 | 理由 |
| --- | --- | --- |
| 言語 | **TypeScript** | ゲーム状態が複雑になるため型で守る |
| ビルド | **Vite** | 軽量で開発体験が良い |
| 描画 | **HTML5 Canvas + PixiJS**（MVP は素のCanvasでも可） | ドット絵2D表現と多数スプライト描画に強い |
| UI | **DOM + CSS**（ボタンやメニュー） / Canvas（マップ） | UI は HTML、ワールドは Canvas のハイブリッド |
| 状態管理 | 単方向データフロー（reducer/イベント方式）。`GameState` を1オブジェクトに集約 | セーブ・ロード・タイムスリップが容易 |
| 保存 | **localStorage**（JSON シリアライズ） | MVPで十分。将来は IndexedDB / クラウド |
| テスト | **Vitest** | ロジック（栽培・経済）のユニットテスト用 |
| デプロイ | 静的ホスティング（GitHub Pages / Cloudflare Pages 等） | 静的サイトで完結 |

実装ディレクトリ構成・モジュール分割は実装計画フェーズで詳細化する。

## 9. MVP 受け入れ基準（フェーズ1 完了条件）

- [ ] 新規ゲーム開始 → 初期所持金でハウス1棟を建てられる
- [ ] 区画に大玉トマトを播種でき、ステージが日進行で進む
- [ ] 水やり / 追肥アクションが品質に影響する（差がスコアで見える）
- [ ] 収穫時に S / A / B / C のいずれかのグレードが算出される
- [ ] 出荷で所持金が増える
- [ ] 所持金で2棟目以降のハウスを建てられる
- [ ] 農園主がレベルアップし、スキルポイントを振れる
- [ ] localStorage によるセーブ / ロードが機能する
- [ ] ブラウザリロード後も状態が復元される
- [ ] 主要操作は **モバイルブラウザでタップだけで完結**する

## 10. 将来拡張ロードマップ（フェーズ2 以降）

実装容量と効果のバランスから、以下の順序での導入を推奨。

1. **従業員雇用 & 配置（5.1）** — ゲームに人格が増え一気にカイロ感が出る
2. **研究開発（5.2）** — 長期目標が生まれる
3. **施設拡張（5.4）** — 経済の伸び代を作る
4. **市場変動・出荷契約（5.6 の一部）** — 経営の駆け引き
5. **品種改良（5.3）** — 大玉トマト特化の最大の差別化
6. **環境・気象・病害虫（5.5）** — リスクと深さ
7. **イベント・評価値（5.6 残り）** — 賑やかさと達成感
8. **ストーリー / 目的モード（5.7）** — 完成形のクロージング

## 11. アートスタイル方針

- **カイロソフト作品風のドット絵を独自製作**する。
- 解像度の方針:
  - マップタイル: 1マス **32×32 px**（暫定）
  - キャラクタ: **16×24 px**（頭身低め、4方向アニメ）
  - UI: ピクセルフォント（日本語ビットマップフォント、または商用利用可のフォントを採用）
- 必要素材リスト（MVP 範囲）:
  - 農園地面タイル（土・草・道）
  - ビニールハウス外観 + 内部床
  - 大玉トマトの生育ステージ別スプライト（少なくとも 4 段階）
  - 農園主キャラ（4方向 × 待機 / 歩行 / 作業）
  - UI アイコン（水やり、肥料、出荷、設定、お金 等）
- **制作体制は未定**（フェーズ1着手時に「自作 / 外注 / 暫定プレースホルダ」を決定）。
- 暫定運用として、絵が揃うまでは**色付きの矩形 + 文字ラベル**で代用してロジックを先行検証する。

## 付録 A: 用語集

- **大玉トマト**: 桃太郎系などに代表される、果実1個 200g 以上の中〜大型トマト。
- **ビニールハウス**: ビニール被覆の簡易温室。本作の標準栽培環境。
- **グレード（S/A/B/C）**: 出荷時の品質ランク。S が最高。
- **生育ステージ**: 種から収穫までの段階。本作では8段階で表現。
- **MVP**: Minimum Viable Product。最小限の遊べる版。
